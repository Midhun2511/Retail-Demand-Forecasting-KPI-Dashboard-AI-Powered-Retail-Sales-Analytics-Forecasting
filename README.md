# 📈 Retail Demand Forecasting KPI Dashboard

An AI-powered Retail Demand Forecasting and KPI Dashboard built using Python, Streamlit, Plotly, and Prophet to analyze retail sales trends, monitor key business metrics, and forecast future demand.

## 🚀 Project Overview

Retail businesses often face challenges such as:

- Overstocking products
- Understocking high-demand items
- Poor demand planning
- Revenue loss due to inaccurate forecasting

This project solves these problems by combining **data analytics, KPI monitoring, and machine learning forecasting** into an interactive dashboard.

The system provides real-time retail insights and predicts future demand to support better inventory and business decisions.

---

## 🎯 Objectives

- Analyze historical retail sales
- Monitor important business KPIs
- Identify top-performing stores
- Evaluate promotional impact
- Forecast future product demand
- Improve inventory planning
